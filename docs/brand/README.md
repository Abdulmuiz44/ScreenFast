# ScreenFast Brand Assets

This folder contains the first logo direction for ScreenFast.

- `screenfast-mark.svg`: square app-style mark for launcher, installer, splash, and favicon-style uses.
- `screenfast-logo.svg`: horizontal mark plus wordmark for docs, headers, and marketing surfaces.

Design direction:

- Professional Windows-native recorder identity.
- Minimal screen/window frame to signal capture.
- Forward chevrons to signal speed and fast export.
- Small red recording dot to keep the screen-recorder meaning clear.
- Deep charcoal, white, electric blue, and red accent palette.

The assets are SVG so they can be imported into Canva and resized without quality loss.
